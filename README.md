# Sistema de Cálculo de Média Escolar 

Um script simples em Python desenvolvido para calcular a média de duas notas de um aluno e informar se ele foi APROVADO ou REPROVADO.

 # Tecnologias Utilizadas 

**Linguagem: Python**

Ambiente: Qualquer editor de código (como VS Code) ou terminal.

# Como Executar o Projeto

Siga os passos abaixo para rodar o código na sua máquina:

Certifique-se de ter o Python instalado no seu computador.

Crie um arquivo com o nome de calculadora_notas.py e cole o nele.

Abra o terminal (ou prompt de comando) na pasta onde o arquivo foi salvo.

Execute o seguinte comando:

python calculadora_notas.py


# Exemplo de uso

- **Primeiro passo,** digite a primeira nota, 
- **Segundo passo,** depois digite a segunda nota quando solicitado,
- **Terceiro passo,** confira o resultado no terminal!



# Funcionalidades

1. Entrada interativa: Solicita as notas do aluno diretamente pelo terminal.

2. Cálculo preciso: Utiliza uma função dedicada para calcular a média aritmética.

3. Formatação amigável: Exibe a média final arredondada para duas casas decimais.

4. Verificação de status: Avalia automaticamente se a média é igual ou superior a 7.0 para definir aprovação ou reprovação.
